받는 사람 명단부터 채웁니다

누구에게 보낼지가 전부 이 시트 한 장에서 관리돼요.

  1. 명단 구글시트를 엽니다. 👉 명단 시트 열기
  2. 이번에 보낼 사람들을 채웁니다. 컬럼은 4개만 신경 쓰면 돼요:
    넘버링 1, 2, 3… 겹치지 않는 번호  ·  회사명  ·  이름 직함까지 (예: 김수아 매니저)  ·  컨택포인트 이메일 주소
  3. 새로 보내는 캠페인이면 발송상태 칸을 전부 비웁니다.
왜 비우냐면: "발송완료"라고 적힌 사람에게는 시스템이 절대 다시 보내지 않아요. 실수로 두 번 보내는 걸 막는 안전장치인데, 새 캠페인 때 안 지우면 아무한테도 안 나갑니다.

5
시트 메뉴에서 클릭 3번

테스트 1통 → 확인 → 발송

시트 위쪽의 📮 침투부 발송 메뉴만 씁니다. 실수로 눌러도 바로 나가지 않게 잠금이 걸려 있어요.

  1. 1) 첨부파일 매칭 확인 클릭 → 명단 옆 첨부확인 칸에 사람별로 붙을 파일이 표시돼요. ⚠ 없음이 뜨면 그 번호의 파일이 폴더에 없다는 뜻
  2. 2) 테스트 메일 클릭 → 내 메일함으로만 1통 옵니다. 열어서 제목·내용·이름 치환·첨부 파일까지 눈으로 확인
    (처음 실행하면 구글이 권한을 물어봐요 → 계정 선택 → 허용을 눌러주세요. 정상 절차입니다)
  3. 테스트가 마음에 들면: 메일설정 탭의 발송 스위치를 발송가능으로 변경
  4. 3) 실제 일괄 발송 클릭 → 몇 명에게 나가는지 한 번 더 물어봅니다 → 예
  5. 명단의 발송상태 칸에 "발송완료"가 차례로 찍히면 끝! 🎉
안심 포인트: 이미 "발송완료"인 사람은 무조건 건너뛰어요(같은 사람에게 두 번 안 나감). 발송이 끝나면 스위치도 자동으로 다시 잠깁니다. 하루 발송 한도에 걸려 중간에 멈추면, 내일 스위치만 다시 켜고 3)을 누르면 이어서 나갑니다.
자주 걸리는 것: ① 아무한테도 안 나감 → 발송상태에 옛날 "발송완료"가 남아있는지 확인 ② 첨부없음 실패 → 파일명이 번호로 시작하는지 확인 ③ 스위치 잠금 안내가 뜸 → 메일설정 탭에서 발송가능으로 변경
